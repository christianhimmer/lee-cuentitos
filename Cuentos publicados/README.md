# Cuentos publicados

Archivo del material original de los cuentos que **ya están en el sitio**. Es una carpeta local de consulta: no se despliega y no se sube al repositorio.

La versión canónica y publicada de cada cuento vive en:

```
src/content/cuentos/*.md
```

Si hay diferencias entre estos archivos y el sitio, manda siempre `src/content/cuentos/`.

## Qué hay aquí

| Archivo | Contenido |
|---|---|
| `Cuentos.txt` | Recopilación de los 21 cuentos publicados (mayo 2025) |
| `Cuentos De toda la pagina.docx` | Recopilación posterior (marzo 2026) |
| `Aventura en el Lago.txt` | Versiones de las partes 10 y 11 |
| `Pasado a Notion/01–04` | Versiones originales de cuentos publicados |
| `Pasado a Notion/05.txt` | Varios publicados + el inédito «Bosque de Niebla» |
| `Pasado a Notion/Cuento 10 y 11` | Versiones de las partes 10 y 11 |
| `Pasado a Notion/Detalles de los Personajes.txt` | Ficha antigua de personajes |
| `_referencia/Descripción de los personajes.txt` | Descripciones originales de los personajes |

## Reglas

- No editar estos archivos: son respaldo.
- Para corregir un cuento publicado, se edita `src/content/cuentos/<slug>.md`.
- Si se republica o se reescribe un cuento, dejar aquí la versión anterior.
